# IUT Tycoon Reims

Jeu de gestion en vue isométrique : construis et fais grandir l'IUT de Reims, puis les sites de Châlons-en-Champagne et de Charleville-Mézières.

**Jouer :** https://frazy34.github.io/iut-tycoon/

## Installer sur téléphone ou ordinateur

- **Android (Chrome) :** ouvre le lien, menu ⋮ → « Installer l'application » ou « Ajouter à l'écran d'accueil ».
- **iPhone (Safari) :** ouvre le lien, bouton Partager → « Sur l'écran d'accueil ».
- **PC (Edge ou Chrome) :** ouvre le lien, puis l'icône « Installer » dans la barre d'adresse.

Une fois ouvert une première fois, le jeu fonctionne hors ligne. La partie est sauvegardée sur l'appareil ; pour la transférer, utilise Options → Exporter / Importer.
